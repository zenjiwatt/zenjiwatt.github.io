=======================================================
VOLQAN OS - SPOTIFY DEFAULT PLAYLIST DIRECTORY
=======================================================

To set your own default songs, simply place three of your
favorite MP3 files in this folder and rename them to:
  1. song1.mp3
  2. song2.mp3
  3. song3.mp3

The retro Spotify music player will automatically load these 
default files from this folder and query their exact durations
when they are played!

You can also use the "+ Add MP3" button inside the player 
playlist editor to dynamically import other MP3 files 
from anywhere on your computer.
